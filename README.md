# Function and Basic Execution of ClearVision Local  
The Clear Vision Local branch contains the code necessary to be able to run ClearVision locally on your workstation or server.  
In order to properly execute the local version of ClearVsion, use only the Jupyter Notebook (.jpynb) files.  
1. Open/Start Jupyter Notebook in the directory which contains the .jpynb files. The easiest method to do this is by navigating to the directory containing the ClearVision files, then using the object menu by Right Clicking the mouse in the directory and selecting "Open in Terminal". This will, depending on the options configured, open a CMD window in the current directory. This can also be accomplished by opening a command window and changing directory within the command window to the ClearVision directory.
2. Start jupyter notebook by typing 'jupyter notebook' in the command window just opened.
3. Once Jupyter Notebook is open, all the files in that directory will appear in the files tab.
4. If this is the first time running ClearVision from the current directory, the first step will be to run "0 - Setup & Run Website.jpynb". This will configure/setup and start ClearVision
5. If ClearVision has already been setup and run once, then simply running "Website_Launch.jpynb" is all that is necessary to startup ClearVison.
